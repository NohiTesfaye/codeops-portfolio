# 🔄 API Converter

A simple, responsive web tool for converting values between different units or APIs.  
Built with clean UI, centered layout, and minimal CSS for readability.

---

##  Project Structure
- `index.html` → Main UI with form elements
- `style.css` → Styling for converter box and inputs
- `script.js` → Conversion logic (to be implemented)

---

##  Features
- Centered converter box with modern card design
- Responsive layout (works on desktop & mobile)
- Styled inputs, dropdowns, and buttons
- Highlighted result display area
- Minimal, clean CSS for easy customization
